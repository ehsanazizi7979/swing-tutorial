# swing-tutorial

## Study guide

A single-file HTML companion with plain-language key points for every lesson (1–86):

- [`swing-lessons-key-points.html`](swing-lessons-key-points.html) — open it in any browser. Every lesson has key points plus a short code example you can copy. It works offline, has search (`/` to focus) that also matches code, per-lesson checkboxes with saved progress, collapse/expand per section, "Show all code", and a print layout.
